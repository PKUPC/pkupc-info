# 项目适配说明（非 SOP 原文）

完整 SOP 见 [Lark 全文纯文字版](lark-sop.txt)，由 `lark-cli docs +fetch` 获取，修订版本 1691。该文件保留正文、代码示例和链接；此处只记录执行时需要核对的项目差异，不替代原文。

- 当前目标路径是 `content/wechat-official-account/mise/`。按 README 使用同名 `.assets/` 目录；黑色多题已有范例为 `heise-001.mdx`。
- 元数据示例中的编号、作者、时间和 QQ 号都是需要填写的字段，不作为新题的默认事实。对照现有 `authors.yml` 和原文署名；缺失资料记录待确认项。
- 当前模板生成脚本会覆盖同名文件，运行前确认目标文件未被使用。
- 普通题参考 `mise-037.mdx`；特殊答案参考 `mise-026.mdx`；图片里程碑参考 `mise-030.mdx`。组件实际行为以当前 `src/components/AnswerCheck.tsx`、`src/utils/formatString.ts` 和 `src/theme/MDXComponents.js` 为依据。
- SOP 指示在下一篇找解析；执行时按题名核对，遇到黑色多题、独立解析篇或停更时逐题配对。解析合并到题目页，避免把解析专篇生成为新的空题页。
- SOP 的提示流程需要真实公众号回复。取提示口令不是提示正文；已有回复可由用户提供。向公众号发消息仍需用户明确授权。
- 本地已有 `heise-001.mdx` 使用原文链接呈现投票结果，并将六道题及解析置于同页。不得仅根据对照表“解析专篇未搬运”就断言这些题的解析缺失。
- 纯文字版保留了一幅 Details 示例图的原链接，图片像素内容未被转写；不得把该部分称为图片 OCR 结果。

# 2026-10-07 依赖升级与 Agent 协作建设

## 项目概况

PKU Puzzle Club 中文静态资料站，包含活动存档、剧情与谜题解析、公众号文章，以及浏览器内的答案验证、历史提交、答案遮挡、解析折叠和轮播。图片预览转换配置于活动文档，不包含公众号文章的普通图片。

技术栈：Docusaurus、React、TypeScript、Ant Design、Tailwind CSS、MDX、PostCSS、pnpm。
没有比赛后台、数据库或保密的服务端验证。

## CI 与协作

PR 到 main 执行 lint、类型检查、Pages 子路径构建；main 推送执行同等检查后部署。
Node 版本从 `.node-version` 读取，pnpm 从 `packageManager` 读取，安装使用 frozen lockfile。
checkout / setup-node 升级至 v6；Pages 上传和部署步骤保留。

新增 `AGENTS.md`、`CONTRIBUTING.md` 和 PR 模板，以及 `pnpm check`、`pnpm verify` 统一验证入口。
不同模型无需特定插件，只需读取文件，遵守内容规范和验证/交接要求。
原有未跟踪的 `pnpm-workspace.yaml` 保留，本次不修改或纳入交付。

## 检查与依赖审计

已通过 frozen lockfile 安装、`pnpm verify`（lint、类型检查、默认路径构建）和
`GITHUB_PAGE_MODE=true pnpm build`。本地验证阶段尚未运行远程 CI；后续 PR 的结果以 GitHub Checks 为准，本次不合并或部署。

审计发现的构建依赖使用限定受影响版本或父依赖的 overrides 修复：
`tinypool` 2.1.2、`serialize-javascript` 7.0.5、`picomatch` 2.3.2、`uuid` 11.1.1、`postcss-selector-parser` 7.1.6。
